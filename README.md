# GSB Bugfix Task
## 题面
支付回调会被平台重复投递，订单服务没有幂等保护，同一笔通知能发两次货；回调体被改了金额后仍能通过校验；旧通知隔很久还能重放；摘要头和请求体编码不一致时结果不稳定；十六进制大小写和长度没有归一。callback_seal.py 的 CallbackSeal 负责 sign 和 verify。实现要用原始请求体生成摘要，把时间戳纳入摘要，比较过程不提前返回，限制可接受的时间范围，已消费的摘要再次出现要拒绝，先校验摘要格式和参数类型；密钥、时间戳和摘要非法抛 ValueError。 支付平台会并发重试同一笔通知，验签和幂等消费必须在一个原子步骤里完成；通知体可能被网关重新编码，签名要基于收到的原始字节。

## 运行方式
```bash
python -m pytest tests -q
```
