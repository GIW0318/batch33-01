# GSB Bugfix Task
## 题面
运营把用户昵称和备注导出成 CSV，Excel 打开后公式直接执行：等号、加号、减号、@、制表符和回车开头都能触发，字段里的逗号和双引号没有按 CSV 规则处理，NUL 也原样写进文件。csv_guard.py 的 CsvGuard 负责 sanitize 和 row。实现要在危险前缀前加单引号隔离，双引号翻倍，含逗号的字段整体加引号，NUL 和控制字符直接拒绝，非字符串先转成字符串再处理。 导出文件会被不同地区的 Excel 打开，除了公式前缀，还要处理前导空格、BOM 和全角符号；脱敏后的字段不能影响列数和行结构。

## 运行方式
```bash
python -m pytest tests -q
```
