# GSB Bugfix Task
## 题面
运营后台接入第三方图表组件后，安全评审发现跨域响应把带凭据的接口暴露给了任意站点：配置里允许携带 cookie 的同时还返回星号，请求来源被原样写回，来源为空也放行，预检把调用方要的自定义头全部抄回，缓存层没有按来源区分。cross_origin_policy.py 的 CrossOriginPolicy 负责 headers。实现要精确比对来源，带凭据时不能使用星号，预检只回允许的方法和固定头列表，响应必须带按来源变化的缓存标记，来源为空或格式非法时拒绝；配置本身非法抛 ValueError。 同一套接口会服务网页、桌面客户端和移动 WebView，来源校验要按调用方分别配置；预检结果会被浏览器缓存，权限变更后不能继续使用旧结果。

## 运行方式
```bash
python -m pytest tests -q
```
